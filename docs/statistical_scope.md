# Statistical scope

The code implements statistical procedures that can be defined transparently from the Figshare package itself. It does not tune analyses to reproduce paper-reported values.

Primary outputs: descriptives, reliability, Pearson/Spearman correlations, OLS, standardized slopes, VIF, influence diagnostics, nonparametric bootstrap, KMO/Bartlett, PAF EFA, EFA-derived CR/AVE, and chi-square sensitivity.

Not implemented as claims: causal inference, panel models, country effects, CFA/SEM, mediation, moderation, latent growth models, machine-learning prediction, or inferential procedures that require unavailable design information.
